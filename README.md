## Structure

- `index.html` — 원페이지 포트폴리오
- `styles.css` — 픽셀 HUD 스타일과 반응형 레이아웃
- `app.js` — 메뉴, 스크롤, 모션, 상호작용
- `assets/` — 대표 아트와 프로젝트 이미지
- `playtests/` — 기존 Web Playtest 보존

GitHub Pages는 `main` 브랜치 루트에서 배포됩니다.
